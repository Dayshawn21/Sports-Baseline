# Fix: Remove the legacy suggested parlays endpoint

**Type:** Fix

**Fixes:** F-71 (the `/tennis/parlays/suggested` part)

**Branch:** `fix/remove-suggested-parlays`

**Status:** complete 2026-11-18 (merged as PR #46, `08bf91e8`; archived 2026-11-18 because the merge left it unarchived)

## The problem

`GET /tennis/parlays/suggested` (`api/app/routers/tennis.py:494-502`) is a legacy alias that only calls `get_bankroll_builder` with fixed limits (15 singles, 10 parlays).

- No web code calls it. The web API modules have no `parlays/suggested` request.
- The user confirmed on 2026-11-17 that no external consumer uses it.

## The fix

- Delete the `get_suggested_parlays` route from `routers/tennis.py`.
- In `tests/test_bankroll_builder_cache.py`, drop `/tennis/parlays/suggested` from the 503 test's `path` parametrize, so the test covers only `/tennis/bankroll/today`.
- Add one test that `GET /tennis/parlays/suggested` now returns 404, so the removal is pinned.

### Must not break

- `/tennis/bankroll/today`: its route, schema, limits and 503 behavior stay as they are.
- `bankroll_builder.py`, `SuggestedParlay`, `SuggestedParlaySchema` and `_generate_parlays` stay. The bankroll route still returns parlays.

### Out of scope

| Left alone | Why |
|---|---|
| The rest of F-71: `api_sports_nfl.py`, `api_sports_nfl_key`, `get_rolling_stats_batch`, `seed_elo.py`, `ingest_from_csv`, the web exports | Other files and lanes |
| The `parlays/suggested` mention in `blueprint/context/project-overview.md` | That file is regenerated by `/overview` |
| History files that mention the route | They are records of past work |
| `ParlaysPage` and the web `SuggestedParlay` type | Web lane; they read the bankroll response |
